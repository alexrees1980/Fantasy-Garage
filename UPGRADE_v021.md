# Upgrade to v0.2.1

No new Supabase tables are required.

1. Replace the app files in GitHub with this package.
2. Commit the changes.
3. Wait for Streamlit to redeploy.
4. Refresh the app and log into the vault.
5. Join a Fantasy Garage once.
6. Return to the vault using **Back to The Car Vault**.
7. Use **Use in game** on a vault item.
8. Open Fantasy Garage and confirm it appears in the shortlist.
9. Use **Save to vault** on a game shortlist item to test the reverse direction.
